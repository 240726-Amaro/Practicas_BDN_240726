# Práctica 02: Conexión remota en MySQL

## Descripción de la práctica

Configuración y comprobación del acceso remoto a una base de datos MySQL, incluyendo la creación de cuentas y roles, la asignación de privilegios y la revisión de actividad de la base de datos.

## Actividades realizadas

- Creación y configuración de usuarios remotos de MySQL.
- Creación de roles y asignación de privilegios a nivel de servidor y de base de datos.
- Asignación de roles a usuarios y configuración de roles predeterminados.
- Preparación de respaldos SQL y de una carga de productos de prueba.
- Consultas de verificación de tablas, triggers, usuarios, roles, bitácora y productos.
